# 🍔 FoodHub (v1 & v2)

FoodHub is a series of learning projects built with **React.js**, focusing on improving front-end skills through real-world examples.  
Each version represents a learning step — from fetching APIs to managing state with Redux.

---

## 🚀 Live Demos

- **FoodHub v1:** [food-hub-v1.vercel.app](https://food-hub-v1.vercel.app)  
- **FoodHub v2:** [food-hub-v2-psi.vercel.app](https://food-hub-v2-psi.vercel.app)

---

## 📘 FoodHub v1 — React + TheMealDB API

**Overview:**  
A simple food recipe app built using React.js and TheMealDB API.  
Users can browse meals, view details, and explore recipes.

**Key Features:**
- Fetch data from **TheMealDB API**
- Display food items dynamically
- Responsive layout using React components
- Ideal for learning **React basics** like props, state, and API integration

**Tech Stack:**
- React.js  
- CSS  
- TheMealDB API  

---

## 🍟 FoodHub v2 — React + Redux

**Overview:**  
An upgraded version built to learn **Redux state management**.  
This version uses a **local JSON file** instead of an API and adds cart functionality.

**Key Features:**
- Add to Cart / Remove / Clear All
- Calculate Total Price
- Search food from local JSON file
- Built with **Redux Toolkit** for global state management

**Tech Stack:**
- React.js  
- Redux Toolkit  
- CSS  
- Local JSON Data  

---

## 🧠 Learning Goals
- Understand React fundamentals (components, state, props)
- Practice working with APIs
- Learn Redux for state management
- Build real-world UI functionality (Cart, Search, Filter)
